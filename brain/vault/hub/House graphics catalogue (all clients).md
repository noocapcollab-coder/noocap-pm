# House graphics catalogue (all clients)

The shared catalogue. Clients pick favourites, change details, or switch items off in their own `GRAPHICS.md`.
Reference codes (v01–v08, f01–f04, t01–t04) point to `clients/lindsay/references/`, where this catalogue was first built.
Every graphic is delivered as a TOP (1080×960) or FULL (1080×1920) clip. No captions; headline typography only (see STYLE.md). Each row becomes a reusable template in `library/`.
All entries use the house "rise + focus" entry from `house/STYLE.md` unless noted.

| # | Kind of line | Graphic | Reference | Notes |
|---|---|---|---|---|
| G1 | **Introducing a tool** ("it's called MiroFish", "someone built an AI tool…") | Real app icon tile + **name decode** animation beside or under it | v05, v02 @10s, v01 @1s | Accent = the tool's brand colour. Name in sans 800. |
| G2 | **Competitor callout** ("you don't need Sora or Kling anymore") | Competitor icons, each one **crossed out in red** as it's named, swapping in place | v06 | End on the "use this instead" tool as a G11 headline ("just use *this*"). |
| G3 | **List / "5 tools you need"** | Serif-italic ordinal ("the *first*") above the real icon card, tool name in bold sans below; a 1–5 counter up front | v04 | Same position and size for every item so the list reads instantly. Intro card: "these 5 *free*…" with numbers 1–5 dropping in. |
| G4 | **Several things named in one line** ("scraping, monitoring, keywords") | Cards appear **left to right, one per word**, staggered on each spoken word | v08 | Max 4 per row; a 5th wraps to a second row. Each card: icon + label (+ number if any). |
| G5 | **A number / stat** ("30,000 stars", "444x cheaper") | Big count-up. GitHub stats → real star/fork/watcher cards. Comparisons → two bars plus an "Nx cheaper/faster" pill | v08, v03 @3–6s | Count-up lands on the spoken number. |
| G6 | **Talking about a real product or feature** | Real UI screenshot or screen recording in a window frame; zoom and highlight the exact element; cursor clicks | v01 @12–16s, v07, v02 @12s | Highlight = accent outline box + slight dim of the rest. |
| G7 | **GitHub repository or file** | Live capture of the real page (dark mode); highlight the file or line, then cut into the file | v07, v02 @0s | Capture automatically from the URL. |
| G8 | **How it works / A → B** | Real icons connected by animated dashed lines; check ✓ or ! badges on outcomes | v01 @20–21s, v03 @25–28s, v04 @21–25s | Lines draw in the direction of the flow. |
| G9 | **Code / install / command** | Dark terminal card; command types in, then an output line with a green ✓ | v01 @17–18s, v04 @13–19s | Real command text from the script or README. |
| G10 | **Money / results** | Stacked notification cards (Stripe-style) sliding in with amounts | v01 @4–5s | Only real or clearly illustrative numbers; never invent claims. |
| G11 | **Punchline / key phrase** | Headline typography: sans + serif-italic word ("I built a *system*"), over a blurred real screenshot or a plain background | v05 @0.9s, v06 @3.2s, t01, t04 | 1–4 words. Usually FULL. |
| G12 | **Showing many examples / outputs** | Real websites or images as floating cards, slight 3D tilt, drifting | v01 @2–3s, @49–52s | Use for "look at what people built". |

| G15 | **Call to action / comment keyword** | Serif italic keyword in curly quotes (“REPO”) in the client accent, TOP clip | v03 @38–39s, t03 | Keyword from the client's KEYWORDS file. |
| G16 | **Several tools / "here's a free…" roundup** | **Fanned card stack**: real UI screenshots as tilted, overlapping rounded cards dealt in one by one | f01 | 3–5 cards, each landing on its name. |
| G17 | **GitHub stars / "look how popular"** | Real repository page on an **iMac mockup** over a soft nature photo; star count highlighted in the accent; flip or count-up to the number | f04 | FULL or TOP. |
| G18 | **Big money / big number** | **Flip counter** (black tiles) under the real app icon + name, with a emphasis word in the `positive` colour | t01 | "$1,000,000,000" rolls in from the right. |
| G19 | **One tool, many models or parts** | Real UI in an outlined rounded frame on `ink`, with **tree connector lines** branching down to real icons | f03 | Lines draw top to bottom, then icons rise and focus in. |
| G20 | **Brand-block moment** (e.g. Claude) | Full-bleed block in the tool's brand colour with its real logo and wordmark | Lindsay's videos | TOP. |

**Rule of thumb:** if a line names something, show *that exact thing*. If it names a number, count it up. If it names several things, give each one its own card on its own word.
