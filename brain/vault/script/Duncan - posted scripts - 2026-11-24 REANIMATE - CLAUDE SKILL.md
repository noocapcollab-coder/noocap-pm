    Hook 2:
There's a Claude skill that reverse engineers motion graphics. You drop in a video and it rebuilds the whole animation in code, for free.
    Body:
So here's the deal. Whatever your project runs on, whether that's CSS, GSAP, Framer Motion or Three.js, this thing rebuilds the animation right inside it. You feed it a live site, a screen recording, an mp4, a gif or a Lottie file, and it breaks the reference down frame by frame: every element on screen, when it starts, how long it runs, the easing and the stagger. Then it films its own version, lines it up against the original and keeps fixing it until the timing matches. Pretty freaking cool. It's called Reanimate. It's fully open source, there are no API keys, and once it's installed you just run slash reanimate inside Claude Code.
