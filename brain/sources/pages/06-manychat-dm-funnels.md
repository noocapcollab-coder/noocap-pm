# 06 — ManyChat DM Funnels

In one line: When someone comments a keyword on a creator's reel, ManyChat automatically DMs them the lead magnet, asks a few questions and guides them to the creator's paid community.

### What this system does
This is how a viewer turns into a paying member. Someone watches a reel, comments the keyword, and ManyChat sends them a DM with the free guide. For some creators, like Duncan, the DM also asks a few questions to find out who's a good fit and then sends them to the right next step, which is usually the creator's Skool community.

### Who is involved
- Owner: The Ops Manager
- Users: whoever sets up keywords for new reels

### When it runs
Automatically, 24/7, every time someone comments the right keyword. We run ManyChat on 7 creator accounts.

### Tools used

### The journey a viewer goes through
- They watch a reel that says "comment [KEYWORD] for the guide."
- They comment the keyword.
- ManyChat replies to the comment and sends them a DM.
- The DM gives them the lead magnet link.
- For creators with qualification, the DM asks a few short questions.
- They're sent to the creator's Skool community.

### Setting up a keyword for a new reel
- Get the keyword from the script and the lead magnet link from SOP 05.
- Open that creator's ManyChat account [ADD login location].
- Duplicate an existing comment-keyword flow so you keep the same structure.
- Change the keyword and the lead magnet link, and attach it to the new reel.
- Test it by commenting the keyword yourself from a different account and checking the DM arrives.

### Rules
- Always test with a real comment before the reel goes live.
- Use a keyword that's one simple word, so people don't spell it wrong.
- Never edit Duncan's qualification flow without the Ops Manager, because it routes people carefully.
