# NOOCAP Systems — SOP Library

Notion page, last edited 2026-11-13.

This is the home for every system we run at NOOCAP. Each page below explains one system in plain words, and each one has a Loom video that walks you through it on screen. If you're new, start at the top and go down in order.

### How to use this library
- Open the system you need from the list at the bottom of this page.
- Watch the Loom first, because it's the fastest way to see how the system works.
- Read the step by step section while you actually do the task, so you don't miss anything.
- If something breaks, check the "If something breaks" table on that page before you message the Ops Manager.

### Every page follows the same layout

### Learning order for new team members
Editors should learn systems 1, 2, 3 and 14 first.
  Content and strategy should learn systems 4, 5, 6, 7 and 12 first.
  Sales and ops should learn systems 8, 9, 10, 11 and 13 first.

### Who to contact when something breaks
Always go down this ladder in order, and only move to the next step if the one before didn't solve it.
When you report a problem, always send four things in one message: which system, what you were trying to do, a screenshot of the error, and what you already tried.

### Master list of every tool and account
Passwords, API keys and tokens are never written in Notion, Discord or any chat. If you need a login, ask the Ops Manager and they'll share it the safe way.

### Recording tips for the Ops Manager
- Each script runs about 2 to 4 minutes, so keep every Loom short and focused on one system.
- Lines marked [SHOW] tell you what to have on screen while you say that part.
- Paste the finished Loom link into the "🎥 Loom video" spot at the top of each page.
- Anything marked [ADD] is a link or detail you need to fill in before sharing with the team.
