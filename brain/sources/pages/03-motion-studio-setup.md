# 03 — Motion Studio Setup

Notion page under [[NOOCAP Systems — SOP Library]], last edited 2026-11-08.

Loom video: [ADD Loom link]
In one line: Motion Studio is our shared editing setup for motion-graphics videos, and any editor can download it onto their own computer and edit any client's video in that client's style.

### What this system does
Some clients, like Nicole, Lindsay, Valerie and David, have videos with animated text and motion graphics. Motion Studio is the setup we use to make those, built on HyperFrames and run through Claude. All of it lives in one private GitHub folder (a "repo"), so every editor has the exact same setup with every client's style already saved inside it.

### Who is involved
- Owner: The Ops Manager
- Users: editors working on motion-graphics clients

### When it runs
You set it up once on your computer, and then you update it before each editing session so you always have the latest client styles.

### Tools used

### First-time setup
- Ask the Ops Manager to add your GitHub account to the private Motion Studio repo [ADD repo link].
- Install the Claude desktop app and log in with the shared NOOCAP Max account (the Ops Manager will give you the login).
- Download (clone) the repo onto your computer.
- Open the folder in Claude Code and run a short test edit to check everything works.

### Every time you edit
- Pull the latest version of the repo so you have any new style updates.
- Start a new chat in Claude named after the client and the video.
- Tell Claude which client it is, so it loads that client's style.
- Give it the script and the footage, then review the output carefully before handing it in.
- Hand in the finished video through the review flow (SOP 02).

### Rules
- Always pull the latest repo before you start, or you might edit with an old style.
- Each editor uses their own chat on the shared account, so never continue someone else's chat.
- Never change a client's style files without asking the Ops Manager first, because everyone shares them.
- Never share the shared Claude login with anyone outside the team.
