# 05 — Lead Magnet Production

In one line: We turn every reel script into a free guide page in Notion, which people get when they comment on the reel, and each guide points them to that creator's community.

### What this system does
A lead magnet is a free resource we give away in exchange for attention, like a step-by-step guide that matches the reel. When someone comments the keyword on a reel, they get sent this guide. We make the guides in Notion using Claude, and every guide ends by pointing people to the right paid community for that creator.

### Who is involved
- Owner: The Ops Manager
- Users: the content team

### When it runs
For every reel that has a comment-keyword call to action, ideally before the reel is posted.

### Which community each creator links to

### Step by step
- Take the approved reel script.
- Ask Claude to turn it into a lead magnet page in that creator's LEAD MAGNET database.
- Check the page reads clearly, the steps are correct, and the community link at the bottom is the right one for this creator.
- Publish the page so it can be opened by anyone with the link, and copy that link.
- Give the link to whoever sets up the ManyChat keyword for that reel.

### Rules
- Always check the community link matches the creator, because sending people to the wrong community loses the sale.
- The guide must deliver what the reel promised, so never publish a half-finished one.
- Every lead magnet goes into that creator's own database, never a shared folder.
