# PM lessons: WhatsApp

Mistakes the PM made once and the rule that came out of each.

## One WhatsApp card per draft
When: A draft is shown to Harsh or Pratham on WhatsApp
Do: Send the draft card once; if the person writes again about the same draft, answer in text or act on it
Never: Send the same draft card twice in a row
Seen 1 time(s). Source: System check.
## "Add N videos" means new cards, not script notes
When: Harsh tells the PM on WhatsApp to add videos, cards or a multi-video campaign for a creator
Do: Create one card per video on that creator's board (with the brief link and date he gave) under the right deal, and ask once which deal it belongs to if unclear
Never: Never turn it into 'script feedback' for Rudraksh on an existing deal
Seen 1 time(s). Source: System check.
## A message about another creator never answers this creator's question
When: Harsh writes on WhatsApp while a brand question for the same brand but a different creator is open (two ElevenLabs deals, one Duncan and one Chris).
Do: Match the answer on brand AND creator. If the message names another creator, treat it as news for that creator's deal (or a new deal) and leave the open question waiting.
Never: Never write a reply from a message that names a different creator, and never state facts in a brand email ("we've checked, the post is live") that nobody gave you.
Seen 2 time(s). Source: System check.
## A file Harsh sends is never dropped
When: Harsh sends a file, code or link on WhatsApp while another draft for that brand is waiting
Do: Work out which brand and thread the file is for (ask once if unclear), then draft the email carrying that file word for word in that brand's thread, alongside any draft already waiting.
Never: Answer a file from Harsh with 'a reply for that thread is already waiting' and show the old draft instead.
Seen 1 time(s). Source: System check.
## Only use WhatsApp templates Meta has approved
When: The 24-hour WhatsApp window is closed and the PM needs to reach Harsh or Pratham
Do: Use a template name that exists and is approved in Meta; if a send fails with 'Template name does not exist', fall back to an approved template and raise it in #pm-alerts once.
Never: Ship a new template name in code before Meta approves it, or let failed pushes fail silently.
Seen 18 time(s). Source: System check.
## Brand requests at night are kept
When: A brand asks for something while WhatsApp is quiet or closed
Do: Queue the question and deliver it with the next message or the morning round-up.
Never: Drop it.
Seen 1 time(s). Source: Rulebook.
## 'Yes' confirms every proposed change
When: Harsh says yes to a list of changes on WhatsApp
Do: Apply all of them.
Never: Apply only the first one.
Seen 1 time(s). Source: Rulebook.
## Ask Harsh for things only we have
When: A brand asks for ad codes, a UID, an account email, a contract, files, alone or together with a script
Do: Ask Harsh on WhatsApp, then draft from his answer word for word.
Never: Draft a promise email instead.
Seen 6 time(s). Source: Rulebook.
## One WhatsApp message per thing
When: Alerting Harsh
Do: Send each thing once. Discord pm alerts are mirrored to WhatsApp, so never send both.
Never: Send near-duplicate messages or ask about team work (scripts, cuts, uploads).
Seen 4 time(s). Source: Rulebook.
## WhatsApp deals get WhatsApp alerts
When: A deal came in on WhatsApp
Do: Alert Harsh (script ready, posted).
Never: Email the brand.
Seen 1 time(s). Source: Rulebook.
